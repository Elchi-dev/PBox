# Security

PBox runs code from game files and sandboxes it, so a way for a game, a patch
file or a plugin to reach outside its sandbox is a vulnerability. So is a
malformed file that makes PBox itself crash in unsafe code.

Please report vulnerabilities privately by mail to
[github@elchi.dev](mailto:github@elchi.dev), not in a public issue. You get an
answer within a week.

Only the latest release and `main` get fixes.
